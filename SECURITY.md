# Security

Please do not open a public issue for a vulnerability that could expose
recordings, transcripts, API keys, calendar credentials, or local files.

Report security issues privately through GitHub Security Advisories:

1. Open the repository's **Security** tab.
2. Choose **Advisories**.
3. Select **Report a vulnerability**.

Include the affected version, macOS version, reproduction steps, and expected
impact. Do not include real meeting data or credentials.
